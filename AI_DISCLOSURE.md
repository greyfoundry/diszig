# AI disclosure

Diszig is being developed with assistance from AI tools. The initial engineering specification, documentation and repository bootstrap were AI-assisted. Future contributions may use agents for research, architecture, code, tests, documentation, debugging and review.

A human contributor remains responsible for every submitted change. Our policy requires material AI assistance to be disclosed and changes to be understood, reviewed and tested by humans before merge. This describes the project's requirements, not a claim that every proposed file or change has already been independently reviewed or tested.

Diszig is intended to run without AI services. There is no required inference provider or AI telemetry in the SDK.

See [AI_POLICY.md](AI_POLICY.md) for contribution requirements and individual pull requests for material assistance and verification disclosures.
