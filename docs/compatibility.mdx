---
title: 'Compatibility'
---

Zig 0.17.1 is the initial research baseline. The actual compiler support range will be established by tested builds and examples. Linux, Windows and macOS on x86-64 and ARM64 are targets, not verified support claims. A focused standard-library probe and the root package's unit tests currently pass in Debug and ReleaseSafe on Windows 11 x86-64; that is build evidence for one host, not SDK platform support.

Diszig targets Discord's documented v10 API initially. Official protocol documentation takes priority over the preview OpenAPI schema. Diszig and Zig have independent version numbers; Zig 1.0 migration is a design goal, not a promise that current code works on an unreleased compiler.
