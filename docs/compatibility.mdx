---
title: 'Compatibility'
---

Zig 0.17.1 is the initial research baseline. The actual compiler support range will be established by tested builds and examples. Linux, Windows and macOS on x86-64 and ARM64 are targets, not verified support claims. A focused standard-library probe and the root package's unit tests currently pass in Debug and ReleaseSafe on Windows 11 x86-64; that is build evidence for one host, not SDK platform support.

## Discord REST versions

- **v10 is the default and full implementation target.**
- **v9 is explicit opt-in.** The transport can target v9, but endpoint-by-endpoint v9 compatibility is not claimed until tested. Shared behavior is reused; genuine v9 differences must be recorded before support is announced.
- **v8 and older are unsupported.** Discontinued versions are not sent requests.
- **v11+ is a future target.** No fictional endpoints, types or fallbacks are added before Discord publishes a stable version and a reviewed source baseline.

Selecting a version never changes Gateway, Voice, DAVE, OpenAPI or Diszig SDK versions. There is no silent downgrade, implicit fallback or retry against another API version.

## Evidence matrix

| Target | Evidence |
| --- | --- |
| Windows 11 x86-64 | Native Debug/ReleaseSafe tests, package fetch, HTTP transport fixture |
| Ubuntu x86-64 | Hosted CI tests and package/transport gates |
| Windows x86-64 (CI) | Hosted CI tests and package/transport gates |
| Linux x86-64/aarch64, macOS x86-64/aarch64, Windows aarch64 | Compile-only `cross-check` of protocol and REST modules |
| Live Discord | Not tested |
| libdave v1.3.0 ABI probe | Windows x86-64 only, 2026-11-27: protocol 1 with a generated MLS key package |
| Opus v1.5.2 probe | Windows x86-64 only, 2026-11-27: 20 ms frame encoded to 3 bytes and decoded to 1920 samples |
| Voice transport | Not implemented; no platform claim |

Compile-only targets are not runtime support claims. No macOS or ARM64 native run has been made.

Official libdave v1.3.0 release assets exist for Windows x64, Linux x64/ARM64 and
macOS x64/ARM64; there is no Windows ARM64 asset. The optional `voice-probe`
step links the verified asset for the host platform and is not part of
`zig build check`. No voice connection, audio path or DAVE session with a remote
peer has been verified.

Diszig targets Discord's documented v10 API initially. Official protocol documentation takes priority over the preview OpenAPI schema. Diszig and Zig have independent version numbers; Zig 1.0 migration is a design goal, not a promise that current code works on an unreleased compiler.
