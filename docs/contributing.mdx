---
title: 'Contributing'
---

Keep changes focused and talk to maintainers before starting substantial architectural work. Read and test the full diff, especially when using a coding assistant. Include relevant protocol references, regression tests, compiler version and limitations in your pull request.

AI-assisted work is welcome and material assistance should be disclosed. Human review is required before merge. The repository's CONTRIBUTING.md and AI_POLICY.md define the full policy. Security issues should be reported privately using SECURITY.md.
