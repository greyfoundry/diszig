---
title: 'Diszig'
description: 'A native Discord SDK for Zig.'
---

Diszig is an independent Greyfoundry project for developers building Discord applications in Zig. We're taking the familiar client, event and builder experience of discord.js and adapting it to Zig's ownership and error-handling conventions.

The SDK is in early development. A Zig build and protocol foundation exist (Snowflake, error context and JSON helpers), but there is no installable release or tested public client API yet. Start with [project status](/status) and the [architecture](/architecture) to see what's implemented and what still needs to be verified.

The core is intended to work without a database, Redis, a separate language runtime or a hosted service. Optional features will have explicit requirements.
