---
title: 'Project status'
---

The project is at planning and repository initialization. Governance, agent workflows, a documentation starter and a repository metadata checker are present. No Zig source, build graph, example bot or CI workflow is present. The initial protocol and networking work has not been implemented or verified. The first functional client release is intended to include REST, Gateway recovery, native and local hybrid sharding, interactions, and legacy and Components V2 message building. Full typed API parity and optional encrypted voice follow in later milestones.

We will distinguish implemented, tested, documented and live-verified features. Experimental or permission-gated Discord APIs will be marked separately. There are no performance numbers or supported platform claims yet.
