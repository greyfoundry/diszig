---
title: 'Project status'
---

The project is in early implementation. Governance, agent workflows, a documentation site, a repository metadata checker, a native Zig build graph and a protocol module are present. The protocol module provides Snowflake parsing and timestamp helpers, bounded and redacted error context, and tolerant inbound JSON helpers. Unit tests pass in Debug and ReleaseSafe on Windows x86-64.

REST, Gateway, client, builders, sharding, voice, examples and CI workflows are not implemented. The first functional client release is intended to include REST, Gateway recovery, native and local hybrid sharding, interactions, and legacy and Components V2 message building. Full typed API parity and optional encrypted voice follow in later milestones.

We will distinguish implemented, tested, documented and live-verified features. Experimental or permission-gated Discord APIs will be marked separately. There are no performance numbers or supported platform claims yet.
